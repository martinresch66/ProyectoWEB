DOCS - Documentación del proyecto
=================================

PROPOSITO
Reunir toda la documentación técnica y de diseño que se entrega con el TPI.

CONTENIDO ESPERADO
1. informe-indagacion.pdf   (máx. 5 páginas)
   - Al menos 2 referencias relevadas y su comparación
   - Modelo de datos con reglas de instrumentos, antecedentes, documentos
     y estados
   - Justificación de arquitectura, offline, sincronización y seguridad
   - Análisis de usabilidad, accesibilidad y privacidad + necesidades
     priorizadas

2. informe-tecnico.pdf
   - Arquitectura y diagramas
   - Modelo de datos (diagrama ER)
   - API REST (métodos, validaciones, respuestas, errores)
   - Matriz de permisos (rol x acción x alcance)
   - Diagrama de estados del trámite
   - Decisiones de diseño y de sincronización
   - Instalación, pruebas y limitaciones conocidas

3. diccionario-datos.md
   - Por cada campo: nombre, formato, obligatoriedad, validación, significado

4. diseno/
   - Archivos o enlaces de Figma, wireframes, prototipos, flujos
   - Arquitectura de información
   - Atomic Design de la app móvil

5. api/
   - Colección Postman u OpenAPI

6. pruebas/
   - Casos de prueba, resultados y test de usabilidad (errores, tiempos,
     mejoras)

7. manual-usuario.pdf   (breve)

8. innovacion.md
   - Mejora propuesta, necesidad que resuelve y validación

ENTREGA FINAL
Todo el proyecto en un .zip con el nombre:
GRUPO_XX_APELLIDO1_APELLIDO2_APELLIDO3.zip
(sin secretos ni datos reales).
